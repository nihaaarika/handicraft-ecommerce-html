# HTML Handicraft Store

A basic HTML project showcasing a simple handicraft store layout.

This project includes:
- Multiple HTML pages
- Product display sections
- Frameset-based layout
- Simple sign-in page
- Static design

---

## 📁 Files

- HTML pages for products (kitchen, wall decor, etc.)
- Frameset files for layout
- Sign-in and terms pages
- Images for products

---

## 🚀 How to Run

1. Download or clone the repository
2. Open any `.html` file in your browser

---

## 📝 Note

This is a basic beginner project created using only HTML.
