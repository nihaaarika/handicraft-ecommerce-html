# 🪷 Handicraft E-Commerce Website

A simple **handicraft e-commerce website** created using **HTML**. This project showcases a static online store layout where users can explore different handicraft products, view product pages, sign in, create an account, and proceed to a basic payment page.

## 📌 About the Project

The **Handicraft E-Commerce Website** is a beginner-friendly web development project designed to demonstrate the use of HTML for creating a multi-page e-commerce website.

The website contains different sections for handicraft products such as **kitchen items, wall decorations, torans, and other decorative products**.

The project uses a **frameset-based layout** to connect different sections of the website.

## ✨ Features

- 🛍️ Handicraft product showcase
- 🖼️ Product images and product pages
- 🍽️ Kitchen-stuff category
- 🏠 Wall-decoration category
- 🪷 Toran/decorative products
- 🔐 Sign-in page
- 📝 New-account registration page
- 💳 Basic card-payment page
- 📜 Terms and conditions page
- 🧭 Multi-page navigation
- 🖥️ Simple static website design

## 🛠️ Technologies Used

- **HTML5**
- **Frameset**
- **Images**

> This is a static front-end project and does not use a backend or database.
